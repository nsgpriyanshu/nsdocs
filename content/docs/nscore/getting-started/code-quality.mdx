## Installing Prettier

Prettier is a widely used code formatter that enforces a consistent style across the project.

Install Prettier as a development dependency:

```bash copy
npm install --save-dev --save-exact prettier
```

Create a configuration file so editors and tools can detect Prettier:

```bash copy
node --eval "fs.writeFileSync('.prettierrc','{}\\n')"
```

Add the following configuration to `.prettierrc`:

```json filename=".prettierrc" showLineNumbers
{
  "printWidth": 100,
  "semi": false,
  "singleQuote": true,
  "trailingComma": "all",
  "tabWidth": 2,
  "useTabs": false,
  "arrowParens": "avoid"
}
```
