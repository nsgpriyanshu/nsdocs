## Initializing a Node.js Project

Start by creating a `package.json` file. This file manages dependencies, scripts, and metadata.

```bash copy
npm init -y
```

This command generates a default `package.json` in the project root.

---

## Installing TypeScript

Install TypeScript as a development dependency:

```bash copy
npm install -D typescript
```

TypeScript will be used to add static typing and improve code reliability.

---

## Creating a TypeScript Configuration

Initialize a TypeScript configuration file:

```bash copy
npx tsc --init
```

This command creates a `tsconfig.json` file, which controls how TypeScript compiles the project.

---

## Recommended Project Structure

A simple and scalable folder structure is recommended:

```txt
project-root/
├─ src/
│  ├─ index.ts
│  ├─ commands/
│  ├─ events/
│  └─ utils/
├─ dist/
├─ package.json
├─ tsconfig.json
└─ node_modules/
```

- `src/` contains all source files.
- `dist/` will contain compiled JavaScript output.
- `index.ts` acts as the application entry point.

---

## Updating TypeScript Configuration

Open `tsconfig.json` and ensure the following options are set:

```json
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "CommonJS",
    "rootDir": "src",
    "outDir": "dist",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true
  }
}
```

These settings provide a balance between safety and compatibility.

---

## Adding Build Scripts

Update the `scripts` section in `package.json`:

```json
{
  "scripts": {
    "build": "tsc",
    "start": "node dist/index.js"
  }
}
```

- `build` compiles TypeScript to JavaScript
- `start` runs the compiled bot

---

## Verifying the Setup

Create a simple entry file at `src/index.ts`:

```ts
console.log('Project setup complete')
```

Build and run the project:

```bash copy
npm run build
npm start
```

If the message appears in the terminal, the setup is complete.
