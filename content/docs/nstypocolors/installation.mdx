# Installation

nstypocolors can be used as a **library**, a **CLI tool**, or both.

## Install as a Dependency

For most projects, install it locally:

```bash
npm install nstypocolors
```

or with pnpm / yarn:

```bash
pnpm add nstypocolors
```

```bash
yarn add nstypocolors
```

This includes:

- Full TypeScript typings
- Color utilities
- Gradient presets
- CLI support

## Global CLI Installation

To use the `nstc` command anywhere in your terminal:

```bash
npm install -g nstypocolors
```

Verify installation:

```bash
nstc --help
```

## Node.js Requirements

- **Node.js ≥ 16**
- Works best with modern terminals supporting ANSI colors

## Stable vs Beta Releases

By default, npm installs the **latest stable version**.

If you want to try a beta release:

```bash
npm install nstypocolors@beta
```

Beta versions may include:

- New gradients
- Experimental CLI features
- Breaking changes

Use beta releases only if you’re comfortable testing newer features.

## What’s Installed

When installed, you get:

- Tree-shakable color functions
- Gradient logging utilities
- Optional CLI (`nstc`)
- Zero runtime configuration

No setup files. No config needed.
