# Introduction

**nstypocolors** is a minimal and expressive color & gradient logging library built for modern TypeScript developers.

It focuses on:

- Readable terminal output
- Aesthetic gradients (not noisy rainbows)
- Zero configuration
- Optional CLI support

Whether you're building a CLI, a Discord bot, or a Node.js script, nstypocolors helps your logs look intentional.
