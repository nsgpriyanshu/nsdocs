# Quick Start

nstypocolors is designed to work out of the box with **zero configuration**.

## Basic Usage

Import the color functions you need and log messages directly:

```ts
import { logGreen, logRed } from 'nstypocolors'

logGreen('Server started successfully')
logRed('Failed to connect to database')
```

Each function prints directly to the terminal with clean, readable colors.

## Gradient Presets

nstypocolors includes built-in gradient presets for structured logs:

```ts
import { logSuccess, logInfo, logWarn, logError } from 'nstypocolors'

logSuccess('Build completed successfully')
logInfo('Fetching user data...')
logWarn('Deprecated API usage detected')
logError('Unhandled exception occurred')
```

These gradients adapt automatically to message length and work for both short and long text.

## Using with TypeScript

Type definitions are included by default. No additional configuration is required.

```ts
logSuccess(`Connected as ${client.user?.tag}`)
```

Works seamlessly in:

- Node.js scripts
- CLI tools
- Discord bots
- Backend services

## CLI Usage

If installed globally, you can use the `nstc` command:

```bash
nstc "Build successful" --success
nstc "Fetching data..." --info
nstc "Potential issue detected" --warn
nstc "Process failed" --error
```

This is useful for quick terminal output or shell scripts.
